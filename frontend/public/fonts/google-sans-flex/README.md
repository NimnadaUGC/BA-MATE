# Google Sans Flex local web fonts

These variable WOFF2 subsets are bundled so BA Mate uses the same interface
typeface in the browser, desktop package and offline local build.

- Family: Google Sans Flex
- Upstream: https://github.com/googlefonts/googlesans-flex
- Upstream release checked: v4.007
- Licence: SIL Open Font License 1.1 (`OFL.txt`)
- Subsets: Latin, Latin Extended and Symbols

The application loads only these local `/fonts/google-sans-flex/` assets. The
CSS contains no runtime Google Fonts import.
