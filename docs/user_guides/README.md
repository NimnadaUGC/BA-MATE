The guides include sidebar paths, numbered steps, expected results and review checkpoints. They cover the packaged Mac app and optional source setup; all five provider choices; project permission and qualification; the six-stage workflow; source review and goal selection; stakeholder confirmation; requirements, stories, traceability and safeguards; diagrams and SRS synchronisation; baseline approval and goal completion; controlled changes; chat context and selection controls; saving, backup, restore and troubleshooting.

## Screenshot-led visual tour

New users can follow the [65-page visual field guide](visual-tour/BA-Mate-Visual-Guide-v1.0.0-beta.3.pdf), or browse the [searchable offline gallery](visual-tour/index.html). The [visual guide package](visual-tour/README.md) contains annotated infographic pages, 63 original desktop-size screenshots, editable publication sources, a starting brief and a completed fictional project backup. It demonstrates the six-stage workflow, B1-to-B2 controlled change, settings, project creation and the other main workspaces. The observed disconnected study-service state is labelled explicitly. This supplements the textual guides and their installation and recovery detail.

## Practice materials

- [Fictional cash checkout source](examples/practice-cash-checkout.txt) — import into a separate practice project. All confirmations are explicitly simulated. The first baseline uses a 500-unit limit; the controlled change uses 300.
- [Beta feedback template](examples/beta-feedback-template.md) — copy for a reproducible issue report. Do not include secrets or confidential source text.

During a formal study, follow the researcher's assigned task, condition and stopping point. Familiarisation does not enrol you in a study. The candidate is intended for a small supervised Apple Silicon Mac beta; signing/notarisation, clean-device installation and Windows distribution remain unqualified. Obtain the application itself through the researcher; this folder contains guidance, not an installer or API keys.
